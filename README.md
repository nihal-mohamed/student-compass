# Student Compass

Build the foundation of a professional, modern, responsive student learning-preference assessment website.

IMPORTANT:

- Do not use Supabase or any external database yet.

- Do not implement authentication.

- Do not invent additional assessment questions.

- Do not change the assessment logic I provide.

- Keep the code modular and easy to extend later.

- Use local frontend state for now.

- The website must work properly on desktop, tablet, and mobile.

The website will eventually have this flow:

1. Language selection

2. Question delivery format selection

3. Question 1: learning methods

4. Question 2: how the student can explain their understanding

5. Automatically generated learning profile

6. Results screen

For now, create the project structure and a clean application shell that can support these screens.

Create:

- A responsive main application container

- A consistent header

- A progress indicator area

- A main content area

- Navigation controls

- A clean visual design suitable for students

- Reusable button, card, selection, and typography components

Use a calm, educational, modern visual style. Avoid excessive decoration.

Do not add fake content or placeholder assessment questions unless necessary for the structure.

Make the implementation clean and maintainable because additional functionality will be added in later prompts.
